# Data Structures & Algorithms

**Prerequisites:** 03-javascript or 04-python

DSA taught with a consistent format for every structure: what it is, how it works, when to use it, and a real use case — not just interview trivia.

## Topics In This Module

- [`01-big-o-and-complexity/`](./01-big-o-and-complexity) — **Big O & Complexity**: Measuring how code scales, and reading time/space complexity.
- [`02-arrays-and-strings/`](./02-arrays-and-strings) — **Arrays & Strings**: The most common structure, common patterns (two-pointer, sliding window).
- [`03-linked-lists/`](./03-linked-lists) — **Linked Lists**: Nodes and pointers, singly/doubly linked lists, and when arrays fall short.
- [`04-stacks-and-queues/`](./04-stacks-and-queues) — **Stacks & Queues**: LIFO vs FIFO, and real use cases (undo history, task queues).
- [`05-hash-tables/`](./05-hash-tables) — **Hash Tables**: O(1) lookup, how hashing works, and collisions.
- [`06-trees/`](./06-trees) — **Trees**: Hierarchical data, binary trees, BSTs, and traversal strategies.
- [`07-graphs/`](./07-graphs) — **Graphs**: Nodes and edges, directed/undirected, and representing real networks.
- [`08-heaps/`](./08-heaps) — **Heaps**: Priority queues, and why heaps are the go-to for 'give me the smallest/largest'.
- [`09-recursion/`](./09-recursion) — **Recursion**: Functions calling themselves, base cases, and thinking recursively.
- [`10-searching/`](./10-searching) — **Searching Algorithms**: Linear vs binary search, and the assumptions each relies on.
- [`11-sorting/`](./11-sorting) — **Sorting Algorithms**: Comparing common sorts (bubble, merge, quick) and their tradeoffs.

> Each topic folder contains a `README.md` lesson. Work through them in order — later topics assume earlier ones.
