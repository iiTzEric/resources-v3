# Python (Parallel Track)

**Prerequisites:** 01-fundamentals

A second language, covered as translation from JS concepts you already know — useful for scripting, data work, and backend alternatives (Flask/FastAPI).

## Topics In This Module

- [`01-syntax-and-variables/`](./01-syntax-and-variables) — **Syntax & Variables**: Indentation-based blocks, dynamic typing, and Python's core syntax vs JS.
- [`02-lists-and-loops/`](./02-lists-and-loops) — **Lists & Loops**: Lists, for-in, range/enumerate, and list comprehensions.
- [`03-dictionaries/`](./03-dictionaries) — **Dictionaries**: Python's key/value structure, .items(), and working with nested data.
- [`04-functions-in-depth/`](./04-functions-in-depth) — **Functions In Depth**: Default args, *args/**kwargs, multiple return values, docstrings.
- [`05-classes-and-oop/`](./05-classes-and-oop) — **Classes & OOP**: __init__, self, inheritance, and how Python's OOP compares to JS classes.
- [`06-error-handling/`](./06-error-handling) — **Error Handling**: try/except, raising exceptions, and Python's error-handling idioms.
- [`07-modules-and-packages/`](./07-modules-and-packages) — **Modules & Packages (pip)**: Organizing Python projects and using pip/virtual environments.

> Each topic folder contains a `README.md` lesson. Work through them in order — later topics assume earlier ones.
