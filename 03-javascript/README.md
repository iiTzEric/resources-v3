# JavaScript

**Prerequisites:** 01-fundamentals

JavaScript beyond basic syntax — the language mechanics (scope, closures, this, prototypes, async) that explain *why* JS behaves the way it does.

## Topics In This Module

- [`01-variables-and-types/`](./01-variables-and-types) — **Variables & Types**: let/const/var, primitive types, and how JS represents values.
- [`02-type-coercion/`](./02-type-coercion) — **Type Coercion**: How and why JS converts types implicitly, == vs ===, and the bugs this causes.
- [`03-operators/`](./03-operators) — **Operators**: JS-specific operator behavior, short-circuiting, and nullish coalescing.
- [`04-functions-in-depth/`](./04-functions-in-depth) — **Functions In Depth**: Function declarations vs expressions, arrow functions, default params, arguments.
- [`05-scope-and-closures/`](./05-scope-and-closures) — **Scope & Closures**: Lexical scope, and closures as functions that remember their birth environment.
- [`06-arrays/`](./06-arrays) — **Arrays**: Core methods, map/filter/reduce, and thinking in transformations instead of loops.
- [`07-objects/`](./07-objects) — **Objects**: Object literals, property access, mutation vs copying, and object methods.
- [`08-destructuring-and-spread-rest/`](./08-destructuring-and-spread-rest) — **Destructuring & Spread/Rest**: Unpacking values cleanly, and expanding/collecting values with ...
- [`09-higher-order-functions-and-callbacks/`](./09-higher-order-functions-and-callbacks) — **Higher-Order Functions & Callbacks**: Functions that take/return functions, and why callbacks are everywhere in JS.
- [`10-this-keyword/`](./10-this-keyword) — **The `this` Keyword**: How `this` is determined by call-site, and where it commonly trips people up.
- [`11-prototypes-and-classes/`](./11-prototypes-and-classes) — **Prototypes & Classes**: JS's real inheritance model, and how `class` is sugar over prototypes.
- [`12-modules/`](./12-modules) — **Modules (ES Modules)**: import/export, module scope, and organizing a codebase across files.
- [`13-promises-and-async-await/`](./13-promises-and-async-await) — **Promises & Async/Await**: Representing future values, chaining, and writing async code that reads like sync code.
- [`14-error-handling/`](./14-error-handling) — **Error Handling**: try/catch, throwing custom errors, and error handling in async code.
- [`15-event-loop-call-stack-tasks/`](./15-event-loop-call-stack-tasks) — **Event Loop, Call Stack & Tasks**: What actually happens under the hood when async code runs — microtasks vs macrotasks.
- [`16-dom-and-events/`](./16-dom-and-events) — **The DOM & Events**: Selecting and updating elements, event listeners, and event delegation.
- [`17-fetch-and-http-requests/`](./17-fetch-and-http-requests) — **Fetch & HTTP Requests**: Making network requests from the browser and handling responses/errors.
- [`18-browser-storage/`](./18-browser-storage) — **Browser Storage**: localStorage/sessionStorage, and persisting data on the client.

> Each topic folder contains a `README.md` lesson. Work through them in order — later topics assume earlier ones.
