# Personal Portfolio Site

**Level:** Beginner
**Concepts practiced:** HTML structure & semantics, CSS (box model, Flexbox/Grid), responsive design

## What You're Building

A personal portfolio website — a home page introducing yourself, a projects section, and a contact
section — built with plain HTML and CSS (no JavaScript required, though you're welcome to add
small touches once the core is solid).

## What Concepts It Teaches

This project applies Module 05 (Web Fundamentals) directly: semantic HTML structure, the box model,
Flexbox/Grid layout, and responsive design with media queries — the exact skills from that module's
lessons, combined into one real, complete page rather than isolated exercises.

## Requirements

- A semantic HTML skeleton: `header`, `nav`, `main`, distinct `section`s, `footer`.
- A hero/introduction section with your name and a short bio.
- A projects section listing at least 3 projects (can be placeholder projects if you don't have
  real ones yet), each with a title, short description, and a link (real or placeholder).
- A contact section with at least an email link.
- Fully responsive: the layout should adapt sensibly on both a wide desktop viewport and a narrow
  mobile viewport, using media queries.
- No layout should break or overlap at any reasonable screen width — test by actually resizing your
  browser window.

## Suggested Features

- A navigation bar linking to each section on the page (using anchor links, `<a href="#projects">`).
- A card-based layout for projects, using Grid's `repeat(auto-fit, minmax(...))` pattern from the
  Web Fundamentals module.
- A subtle color scheme and consistent spacing throughout, rather than default browser styling.

## What You Should Figure Out Yourself

- The exact visual design — color scheme, fonts, spacing — is intentionally left to you.
- Whether to use Flexbox or Grid for each specific layout decision (the Web Fundamentals module
  covers when each fits better).
- How to structure your specific content (how many sections, what order) in a way that presents
  you well.

## Possible Extensions

- Add a dark/light mode toggle (this would introduce a small amount of JavaScript, a natural bridge
  toward the JavaScript module if you're working through this curriculum roughly in order).
- Deploy it somewhere publicly accessible (GitHub Pages is a common, free option for static sites).
- Add subtle CSS transitions/animations on hover states for project cards.

## Skills Demonstrated

Completing this project demonstrates genuine command of semantic HTML structure, the CSS box model,
modern layout tools (Flexbox/Grid), and responsive design — the complete foundation the rest of
this curriculum's frontend work (React) builds directly on top of.
