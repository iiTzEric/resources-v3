# Backend Resources

This folder teaches two parallel ways to build an Express API: MongoDB with Mongoose, and PostgreSQL with Prisma.

## Learning path

1. Read [HTML and CSS](Frontend/html-css.md), then [browser JavaScript](Frontend/javascript-browser.md).
2. Read [HTTP and frontend architecture](Frontend/http-and-architecture.md) and use [api-client.js](Frontend/api-client.js) as the browser/API boundary.
3. Read [Node.js and Express](Backend/node-express.md), then choose [MongoDB + Mongoose](Backend/mongodb/mongodb.md) or [PostgreSQL + Prisma](Backend/postgres/Prisma-postgres.md).
4. Read the matching schema/model, middleware, route, and utility files together.
5. Install backend dependencies, configure `.env`, and run the selected database setup before starting the server.
6. Build loading, empty, success, and error states in the frontend before adding advanced UI patterns.

The code examples are building blocks, not a complete production application. Before production use, add tests, HTTPS, secret management, database backups, structured logging, and deployment-specific configuration.
