# Programming Fundamentals

**Prerequisites:** None — this is the starting point.

How computers and programs actually work, and the building blocks every language shares: variables, logic, loops, functions, and how to think about and fix your own code.

## Topics In This Module

- [`01-how-programs-work/`](./01-how-programs-work) — **How Programs Work**: What actually happens when code runs: source code, interpreters/compilers, instructions, execution.
- [`02-variables-and-data-types/`](./02-variables-and-data-types) — **Variables & Data Types**: Naming and storing values; numbers, strings, booleans, and why types matter.
- [`03-operators/`](./03-operators) — **Operators**: Arithmetic, comparison, logical, and assignment operators, and how precedence works.
- [`04-conditionals/`](./04-conditionals) — **Conditionals**: Making decisions in code: if/else, comparison logic, and common ordering mistakes.
- [`05-loops/`](./05-loops) — **Loops**: Repeating work: for loops, while loops, iteration, and when each fits.
- [`06-functions/`](./06-functions) — **Functions**: Reusable blocks of logic: parameters, arguments, return values, and why functions exist.
- [`07-scope/`](./07-scope) — **Scope**: Where variables live and who can see them: global, function, and block scope.
- [`08-data-structures-intro/`](./08-data-structures-intro) — **Data Structures (Intro)**: Arrays/lists and objects/maps as ways of organizing data, before going deep in the DSA module.
- [`09-error-handling-and-debugging/`](./09-error-handling-and-debugging) — **Error Handling & Debugging**: Reading error messages, forming hypotheses, and systematically finding bugs.
- [`10-algorithms-and-complexity-intro/`](./10-algorithms-and-complexity-intro) — **Algorithms & Complexity (Intro)**: What an algorithm is, and a first, gentle look at Big O — deep dive lives in the DSA module.
- [`11-memory-basics/`](./11-memory-basics) — **Memory Basics**: Stack vs heap, references vs values, and why some bugs come from misunderstanding this.
- [`12-input-output-and-files/`](./12-input-output-and-files) — **Input, Output & Files**: Reading input, producing output, and working with files on disk.
- [`13-modules-and-packages/`](./13-modules-and-packages) — **Modules & Packages**: Splitting code across files, importing/exporting, and what a package manager does.
- [`14-apis-http-json/`](./14-apis-http-json) — **APIs, HTTP & JSON**: What an API is, the request/response idea, and JSON as a shared data format.
- [`15-command-line-basics/`](./15-command-line-basics) — **Command Line Basics**: Navigating and using a terminal: the tool you'll live in for the rest of this path.
- [`16-git-and-github-intro/`](./16-git-and-github-intro) — **Git & GitHub (Intro)**: Why version control exists and the core save/sync loop — deep dive lives in its own module.

> Each topic folder contains a `README.md` lesson. Work through them in order — later topics assume earlier ones.
